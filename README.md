# Quiz Linux: Teste seus conhecimentos sobre o mundo Linux!

Este é um divertido jogo de perguntas e respostas sobre Linux, projetado para testar seus conhecimentos e aprender mais sobre o sistema operacional de código aberto mais popular do mundo.

## Como executar o projeto

1.  Clone este repositório para o seu computador.
2.  Abra o arquivo `index.html` em seu navegador.

## Tecnologias utilizadas

*   HTML
*   CSS
*   JavaScript
*   [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)

## Créditos

*   O código para os confetes foi retirado da biblioteca [canvas-confetti](https://www.npmjs.com/package/canvas-confetti).
